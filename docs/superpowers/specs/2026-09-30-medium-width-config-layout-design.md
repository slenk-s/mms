# 中小宽度系统配置页纵向布局设计

**日期：** 2026-09-30
**状态：** 已确认，待实施计划
**范围：** `client/views/config_view.py` 系统配置页在中小宽度下的布局、配置项展开方式、状态展示、数据统计和快捷操作区域。

## 目标

解决中小宽度下配置页连续空白卡片、状态区不可见、快捷操作重叠裁切的问题。保留左侧完整文字导航，不使用图标收起模式；让配置区、状态区、统计区和快捷操作区在有限宽度中保持可读和可操作。

## 布局规则

### 宽屏：内容宽度 >= 1250 px

- 配置区与状态区允许并排。
- 配置区仍采用单选展开：默认展开数据库配置。
- 状态区以紧凑标签切换呈现：默认显示概览。
- 数据统计与快捷操作可并排。

### 中等宽度：900–1249 px

- 左侧导航保持完整文字，不自动折叠。
- 配置区、状态区、数据统计、快捷操作按垂直顺序排列。
- 配置区仅展开一个分组；收起项只保留标题行，不留空白高度。
- 状态区使用一行标签：概览、MySQL、同步、FTP；仅显示被选中状态的内容。
- 数据统计常驻，采用 2×2 网格。
- 快捷操作常驻，操作按钮各占一行；车间切换与车间管理改为上下排列。

### 窄屏：内容宽度 < 900 px

- 左侧导航仍保持完整文字。
- 主内容完全单列，外围滚动区域承担垂直溢出。
- 数据统计从 2×2 网格切换为单列四项。
- 车间切换控件、车间管理按钮、保存/重置按钮按可用宽度自动换行或纵向排列。

## 交互

### 配置区

默认展开数据库配置。以下配置项始终显示标题，点击后展开当前项，并收起同一区其他项：

- 数据库配置
- 同步设置
- 预警设置
- Web 查询服务
- 硬件设备
- 更新 FTP 配置

用户最后展开的配置项持久化，下次进入恢复；无偏好时使用数据库配置。

### 状态区

状态区改为单选标签切换，不再让四张完整状态卡垂直堆叠：

- 概览（默认）
- MySQL 状态
- 同步状态
- FTP 状态

切换仅改变状态内容可见性，不中断 MySQL、端口或 FTP 检测线程；长状态值继续使用 Tooltip / 换行规则。

### 常驻区

- 数据统计默认常驻，不折叠。
- 快捷操作默认常驻，不折叠。
- 快捷操作的导出、导入、清空队列保持完整按钮高度和危险操作颜色。
- 车间切换不允许被压缩到重叠或裁切；中小宽度改为纵向布局。

## 实现边界

- 不重建数据库、同步、预警、Web、硬件或 FTP 表单控件。
- 不改变配置保存、同步、权限和后台检测的业务语义。
- 使用既有 `ConfigGroup` 承载配置区单选展开。
- 为状态区增加轻量标签栏和内容容器；既有 `StatusCard` 对象仅移动/显示隐藏，不重建。
- 保留现有线程关闭与响应式主窗口断点机制。

## 验证矩阵

| 场景 | 期望 |
| --- | --- |
| >=1250px | 配置/状态可并排；配置单选展开；状态标签切换。 |
| 1000px | 状态区下移；无空白配置卡片；统计2×2；快捷按钮不重叠。 |
| 800px | 单列布局；统计单列；车间操作纵向；可滚动。 |
| 配置切换 | 新配置展开时旧配置收起；表单内容不重建。 |
| 状态切换 | 只切换内容可见性；状态检测线程不被中断。 |
| 长状态值 | 显示省略或换行，完整文本可通过 Tooltip 获取。 |
| 中小宽度 | 保存、重置、快捷操作、车间切换均可点击且无裁切。 |

## 验收标准

1. 中小宽度下不再有截图中的连续空白配置卡片。
2. 状态区始终可见并可在四类状态之间切换。
3. 数据统计和快捷操作在中小宽度下完整可操作，不重叠或裁切。
4. 配置区只保留一个展开内容，默认数据库配置。
5. Qt 离屏布局测试、现有同步/UI测试、阻塞级 flake8 和 `git diff --check` 通过。
