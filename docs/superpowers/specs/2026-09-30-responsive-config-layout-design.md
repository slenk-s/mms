# 系统配置页响应式布局与侧栏折叠设计

**日期：** 2026-09-30
**状态：** 已确认，待实施计划
**范围：** `client/main.py` 主壳布局、`client/widgets/navigation.py` 左侧导航、`client/views/config_view.py` 系统配置页及其状态/统计/快捷操作区域。

## 目标

在宽屏保留现有“左侧导航 + 中间配置 + 右侧状态”信息结构；在笔记本、小分辨率和 Windows 125% / 150% DPI 下，避免按钮、状态值、路径、时间和配置项文字被裁切，并允许用户主动折叠侧栏和状态面板。

## 设计原则

- 不按窗口大小等比缩小字体；正文保持可读的最小字号。
- 主业务配置内容优先获得宽度；装饰性空白和次要信息优先收缩。
- 重要长文本使用换行或省略号加 Tooltip，禁止静默裁切。
- 所有布局切换由明确断点控制；用户主动折叠的偏好需要持久化。
- 不改变现有配置保存、同步、权限和状态数据语义。

## 布局模式

### 宽屏模式：窗口内容宽度 ≥ 1400 px

- 左侧导航完整展开，目标宽度 180–210 px。
- 中间主配置区为弹性区域，最小宽度 620 px。
- 右侧状态区常驻，目标宽度 300–340 px。
- 数据统计与快捷操作保持双栏并排。
- 顶部操作按钮保持完整文字。

### 中等模式：1100–1399 px

- 左侧导航默认展开，允许用户折叠。
- 右侧状态区压缩到约 250 px，状态卡内部字段使用标签列和弹性值列。
- 顶部操作区允许换行；最后同步时间改为两行展示或省略号加 Tooltip。
- 底部统计和快捷操作仍并排，但由 `QSplitter` 分配可用宽度。

### 窄屏模式：窗口内容宽度 < 1100 px

- 左侧导航自动折叠为图标栏；用户可临时展开。
- 右侧状态区从主行布局移至配置内容下方，变为全宽或两列自适应卡片区。
- 数据统计与快捷操作从并排改为纵向堆叠。
- 顶部操作按钮使用紧凑间距；空间仍不足时允许按钮行换行。
- 系统配置折叠组和表单保持在 `QScrollArea` 内，确保不会因高度不足裁切。

## 组件改造

| 组件 | 改造职责 |
| --- | --- |
| `MainWindow` | 监听窗口尺寸，向当前页面传递布局模式；让导航栏在窄屏自动折叠。 |
| `NavigationBar` | 提供 `set_collapsed(bool)`；折叠时保留图标、隐藏文字、设置 Tooltip，并保存用户偏好。 |
| `ConfigView` | 用 `QSplitter` 承载主配置区与状态区；实现 `set_responsive_mode(mode)`，在窄屏重排状态、统计和快捷操作容器。 |
| `StatusCard` | 标签和值使用弹性布局；值启用换行/省略与 Tooltip，IP、文件路径、时间等长文本完整可访问。 |
| `ui_settings.py` | 保存 `navigation_collapsed`、`config_status_collapsed` 等布局偏好。 |

## 文字与控件规则

- 正文和卡片内容字体不小于 12 px；关键状态和操作按钮不小于 13 px。
- `QLabel` 状态值：短值单行，长值采用 `QFontMetrics.elidedText()` 并设置完整 Tooltip；诊断/错误值可换行显示。
- 顶部“最后同步时间”、FTP 地址、数据库路径、IP 地址使用弹性宽度，不能挤压主按钮。
- 所有按钮使用 `QSizePolicy.Minimum` 或 `Preferred`，禁止由固定宽度导致文字裁切。
- 对配置页状态卡、统计卡、快捷按钮设置合理 `minimumHeight`，不依赖固定窗口高度。

## 交互

- 左侧导航顶部增加折叠按钮；折叠状态在下次启动恢复。
- 右侧状态区增加“收起/展开”入口；宽屏默认展开，窄屏默认置于主区下方。
- 用户手动展开导航后，在当前会话优先尊重用户选择；窗口恢复宽屏时保留其持久化偏好。
- Tooltip 必须提供被省略文本的完整内容，尤其是同步错误、时间、路径与主机地址。

## 验证矩阵

| 场景 | 期望 |
| --- | --- |
| 1920×1080、100% DPI | 三栏展开，统计/快捷操作并排，所有状态可见。 |
| 1366×768、100% DPI | 顶部按钮可换行，右侧卡片可读，无字段裁切。 |
| 1280×720、125% DPI | 左侧可折叠，右侧状态缩窄但长值有 Tooltip。 |
| 1024×768、125% DPI | 导航自动折叠，状态区移至下方，底部区域纵向排列。 |
| 150% DPI | 不缩小正文；内容可滚动、重排或省略提示，不重叠。 |
| 窗口缩放往返 | 不丢失配置数据、不重复创建控件、不破坏状态卡数据。 |
| 重启应用 | 用户导航折叠偏好恢复。 |

## 非目标

- 本轮不重写库存、登记、资产等全部业务页面。
- 本轮不更改主题颜色、语言资源键或同步业务逻辑。
- 本轮不把桌面端改为网页响应式框架。

## 验收标准

1. 所列分辨率和 DPI 场景中，没有可见的按钮文字、状态值或配置表单标签被静默裁切。
2. 长文本可通过换行或 Tooltip 获取完整内容。
3. 窄屏状态区和底部区域会自动重排，主配置内容仍可操作。
4. 导航折叠可用并在重启后保持用户偏好。
5. Qt 离屏布局测试、现有页面加载测试、阻塞级 flake8 和 `git diff --check` 通过。
