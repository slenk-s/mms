# 三断点一致性系统配置页布局设计

**日期：** 2026-09-30
**状态：** 已确认，待实施计划
**范围：** `client/views/config_view.py` 系统配置页在宽屏、中等宽度和窄屏下的布局行为。

## 核心原则

系统配置页在三种宽度下必须展示相同的信息与功能入口：

- 数据库配置、同步设置、预警设置、Web 查询服务、硬件设备、更新 FTP 配置；
- 概览、MySQL 状态、同步状态、FTP 状态；
- 数据统计、快捷操作、车间切换与车间管理。

不使用卡片折叠、标签隐藏、图标收起或功能入口删除来节省空间。布局只能调整排列方向、网格列数、控件宽度和滚动承载；不得产生空白占位、重叠、裁切或功能缺失。

## 宽度断点

| 模式 | 内容宽度 | 配置/状态 | 统计/快捷 | 车间操作 |
| --- | --- | --- | --- | --- |
| 宽屏 | `>= 1250px` | 横向并排 | 横向并排 | 横向排列 |
| 中等宽度 | `900–1249px` | 纵向排列 | 纵向排列 | 横向优先，空间不足时可换行 |
| 窄屏 | `< 900px` | 单列纵向排列 | 单列纵向排列 | 纵向排列 |

## 三种模式共同要求

1. 六个配置组标题和完整表单内容均可访问；内容由配置区 `QScrollArea` 承载。
2. 四张状态卡均完整可访问；状态区在中小宽度下移到配置区之后，由状态区滚动承载，不隐藏任何状态卡。
3. 数据统计和快捷操作始终显示；快捷操作按钮保留完整高度和危险操作样式。
4. 车间下拉框、车间管理按钮在任何宽度下均不重叠、不裁切。
5. 长状态值使用换行或 Tooltip，不改变状态内容。
6. 左侧导航始终展示完整文字，不进入图标收起模式。
7. 三种模式之间往返切换时，不重建表单控件、状态卡、统计卡或快捷操作控件，不中断后台检测线程。

## 布局实现

- 使用既有 `QSplitter` 只调整横向/纵向 `orientation`，不在普通布局和 splitter 之间重复 reparent。
- 配置区继续使用 `QScrollArea`，确保六个表单在窄屏可垂直滚动。
- 状态区使用独立 `QScrollArea` 或固定内容容器，确保四张完整状态卡在中小宽度下可滚动查看。
- 宽屏统计采用 2×2 网格；中等宽度仍可采用 2×2；窄屏采用单列四项。
- 宽屏快捷操作/车间控件横向排列；中小宽度在空间不足时由 `QVBoxLayout` 或可换行容器承载。

## 验证矩阵

| 场景 | 必须验证 |
| --- | --- |
| 1280px 内容宽度 | 配置/状态、统计/快捷操作横向；六配置组、四状态卡均可见可访问。 |
| 1000px 内容宽度 | 区域纵向；所有配置组、四状态卡、统计和快捷操作仍完整可访问。 |
| 800px 内容宽度 | 单列；配置与状态可滚动；统计单列；车间操作纵向且无裁切。 |
| 三档往返切换 | 所有关键 QWidget 对象身份保持不变，后台线程与状态 timer 不变。 |
| 125%/150% DPI | 文字、按钮、状态值不重叠或静默裁切。 |

## 非目标

- 不修改同步、数据库、FTP、硬件、Web 服务和权限业务逻辑。
- 不修改 `MySQL_/sql配置.pptx`。
- 不重新引入图标折叠导航或卡片单选展开交互。

## 验收标准

1. 三个断点下的功能入口一致，无隐藏或折叠的配置/状态/辅助卡片。
2. 中小宽度下不出现截图中的连续空白、大量裁切或快捷操作重叠。
3. 所有控件可用，布局切换不重建或丢失输入内容。
4. 真实 Python 3.11 离屏测试、阻塞级 flake8 和 `git diff --check` 通过。
